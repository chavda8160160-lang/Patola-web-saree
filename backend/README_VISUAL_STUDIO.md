# Virasat Patola - Visual Studio, SQL Server & Stored Procedures Guide

This guide explains how to run the **.NET Core Web API**, execute the **SQL Server Stored Procedures (SPs)**, connect the **Frontend & Backend**, and test all APIs interactively in **Swagger UI**.

---

## 1. SQL Server Stored Procedures Setup

Before running, execute the T-SQL script in **SQL Server Management Studio (SSMS)** or **Azure Data Studio**:

1. Open SSMS and connect to your SQL Server (e.g. `localhost` or `.\\SQLEXPRESS`).
2. Open file: [VirasatPatola_Schema.sql](file:///c:/Users/Admin/.gemini/antigravity-ide/scratch/patola-saree-web/backend/Data/VirasatPatola_Schema.sql).
3. Press **F5 (Execute)**.
4. This script creates:
   - Database: `VirasatPatolaDb`
   - Tables: `Sarees`, `Bookings`, `Orders`, `OrderItems`, `Subscribers`
   - **Stored Procedures**:
     - `sp_GetSarees`: Retrieves sarees with dynamic filters (`@Category`, `@Motif`, `@Search`, `@MinPrice`, `@MaxPrice`).
     - `sp_GetSareeById`: Retrieves single saree by `@Id`.
     - `sp_CreateBooking`: Saves consultation/loom bookings and returns `@NewBookingId OUTPUT`.
     - `sp_CreateOrder`: Executes order creation with JSON line items (`OPENJSON`) inside an ACID transaction and returns `@NewOrderId OUTPUT`.
     - `sp_SubscribeNewsletter`: Adds email subscriber with duplicate check and returns `@IsNewSubscription OUTPUT`.
   - Seed data for authentic Patola sarees.

## 2. How to Open & Run in Visual Studio

1. Double-click [VirasatPatola.sln](file:///c:/Users/Admin/.gemini/antigravity-ide/scratch/patola-saree-web/VirasatPatola.sln) (or `VirasatPatola.slnx`).
2. In Solution Explorer, right-click **`VirasatPatola.Api`** and select **Set as Startup Project**.
3. Verify your connection string in `backend/appsettings.json`:
   ```json
   "ConnectionStrings": {
     "SqlServerConnection": "Server=localhost;Database=VirasatPatolaDb;Trusted_Connection=True;TrustServerCertificate=True;MultipleActiveResultSets=true;"
   }
   ```
   *(If using SQL Express, change `Server=localhost` to `Server=.\\SQLEXPRESS`)*.
4. Press **F5** (or click the Green Run button).

When you press **F5**, your browser will automatically open Swagger UI at:
👉 **`http://localhost:5000/swagger`** (or `https://localhost:5001/swagger`)

You can test all Stored Procedures directly:

## 4. Frontend & Backend Live Connection

When running the ASP.NET Core project in Visual Studio:
- **Unified Port**: The ASP.NET Core server serves both the **API** and the **Frontend**:
  - Frontend: `http://localhost:5000/` (loads `index.html`)
  - Swagger UI: `http://localhost:5000/swagger`
  - REST APIs: `http://localhost:5000/api/...`
- **Instant Synchronization**:
  - Sarees catalog automatically fetches live from SQL Server via `sp_GetSarees`.
  - Booking consultation form submits directly to `sp_CreateBooking`.
  - Luxury cart checkout submits directly to `sp_CreateOrder`.
  - Newsletter footer form submits directly to `sp_SubscribeNewsletter`.
